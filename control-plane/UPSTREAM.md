# Convoy control plane

Imported from useconvoy/mvp commit `36a1b0d1558b7230d76eac860119f82a6463aa99`. The server, agent, lockfile, tests and pinned SQLite runtime are kept together so the portal uses the verified model gateway and device protocol. The public Next.js portal exposes only its authenticated, allowlisted device views and Chat. No old web application is bundled in this API image. Historical simulator records remain internal and are excluded by the portal.
