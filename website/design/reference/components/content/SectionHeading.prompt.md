SectionHeading opens each landing section with an optional mono eyebrow, a level-appropriate heading and a lead paragraph.

```jsx
<SectionHeading id="how" eyebrow="How it works" title="Package the system. Qualify the release." lead="A proposed three-step workflow." />
```

- One `as="h1"` per page (the hero). Everything else h2; use `as="h3"` inside sections.
